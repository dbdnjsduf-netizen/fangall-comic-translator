## 실행

Node.js에서 `npm install`, `npm start` 후 http://127.0.0.1:3344 접속. 기존 `launch-comic-translator.vbs`로도 실행할 수 있습니다. 코드 업데이트 후에는 서버 재시작과 브라우저 새로고침이 필요합니다.

## 분석 방식

Sol 분석과 이미지 생성 도구 호출은 모두 `gpt-6-sol`을 사용합니다. 이미지 생성 도구 호출의 추론 설정은 medium입니다.

- **Sol 낮음 → 필요 시 높음 (권장):** Sol low 1회로 전체 OCR·번역을 합니다. 모델이 불확실성을 보고하거나 코드 검사에서 문제가 발견된 경우에만 Sol high로 원본 전체를 한 번 추가 검증합니다. 추가 검증은 기존 목록에 없는 텍스트를 추가하거나 잘못 합친 항목을 나눌 수 있습니다. 정상 페이지는 분석 1회, 의심 페이지는 최대 2회입니다.
- **Sol 높음 → 항상 높음 재검증 (기존):** 만화/일본만화는 high 2회, 문서는 high 1회입니다.
- 카드게임은 분석 선택과 무관하게 이미지 직접 번역합니다.

새 사용자 기본값은 조건부 Sol 방식입니다. 기존 브라우저나 배치에 저장된 `terra_single` 선택은 조건부 Sol 방식으로 전환됩니다. API 필드 `analysisMode`는 `sol_adaptive`, `sol_double`입니다. 이전 `solAnalysis` boolean 요청도 수용하며, 과거 `false` 값은 조건부 Sol 방식으로 전환됩니다.

## 검토와 복구

원문/번역 confidence, 페이지 누락·읽기 순서 confidence, needs_review와 구체적 이유를 추가 검증 조건으로 사용합니다. 빈 번역·잘못된 분류·항목 수 불일치·일본만화의 영문 보존 실패도 검사합니다. 숫자·수량·부정·이름의 의미 확인은 모델에 요구하며, 코드가 의미 정확성을 보증하지는 않습니다.

high 검증 후에도 불확실한 결과는 이미지를 생성하되 카드와 번역수정 화면에 **검토 필요** 경고를 남깁니다. 빈 텍스트 등 불완전 결과는 생성을 중단합니다. 자기평가만으로 누락이나 오역을 완전히 검출할 수 없으므로 중요한 결과는 원본과 대조해 주세요.

저장된 번역이 있는 재생성은 분석을 반복하지 않습니다. 생성 설정과 분석 선택은 항목별로 저장합니다. 분석 결과와 페이지 완료 상태를 중간 저장하고 배치 파일 쓰기를 직렬화·원자적 교체합니다. 서버 중단 시 처리 중 항목은 실패로 표시됩니다. 아직 전처리 원본/분석이 저장되지 않은 항목은 재업로드해야 합니다. 1차 분석 중간 결과 자체의 재개는 지원하지 않습니다.

## 한국어 글자 선명도

모든 이미지 생성 경로에 다음 기준을 공통 적용합니다.

- 원본의 서체 성격, 굵기, 기울기, 색상, 손글씨 느낌과 강조를 가능한 한 유지합니다.
- **원본이 흐리거나 저해상도여도 새 한국어 글자는 출력 해상도에서 선명하게 다시 그립니다.** 원본의 JPEG 블록, 흐림, 잡티, 깨진 획을 새 글자에 모방하지 않습니다.
- 명확한 한글 자소와 획, 열린 내부 공간, 깨끗한 가장자리와 적절한 안티앨리어싱을 요구합니다. 지나치게 작게 줄이는 대신 문구를 유지하며 줄바꿈과 간격을 조절합니다.
- 그림·말풍선·꼬리·아이콘·보호영역을 선명화하거나 다시 그리지 않습니다. 일본만화의 보호된 영문 원본도 그대로 유지합니다.

이는 생성 지시이며 모든 글자의 정확도·선명도를 보장하는 픽셀 검증기는 아닙니다. 실제 이미지 생성은 선택한 GPT 이미지 2.0/2.5가 담당하고 Sol medium은 이미지 도구 호출을 담당합니다.

## 처리 설정

기본 분석 워커 2개, 이미지 생성 워커 2개, 전체 모델 호출 상한 4개입니다. 다른 페이지의 분석과 생성이 겹쳐 실행됩니다. OCR 요청별 타임아웃은 `OCR_TIMEOUT_MS`(기본 400000ms)이며 재시도는 `MODEL_STAGE_MAX_RETRIES`(기본 4)입니다. request ID만으로 영구적 HTTP 오류를 재시도하지 않습니다. 이미지 생성의 중복 외부 재시도 루프는 제거했습니다.

분석 시간은 대기·재시도를 포함한 단계 경과 시간이며 결과 세부정보와 저장 JSON에 기록됩니다. 처리 중에는 찌꺼기 삭제를 차단합니다. `번역 기록 지우기`와 다운로드 파일 삭제는 별개입니다.

이미지 모델/추가 요청/사용자사전/보호영역 편집/번역수정/생성본 복구 편집 기능은 유지됩니다. 추가 요청은 이미지 편집 단계에 전달되며 OCR 번역문을 다시 분석하지 않습니다. 일반 페이지는 기존 2K 출력, 큰 펼침면은 기존 4K 계산을 유지합니다.

## 개발 확인

`npm test`로 분석 분기, 최종 결과 검사, 실제 요청의 모델/추론 설정, 모든 이미지 생성 모드의 선명도 지시, SSE 처리를 오프라인 검사합니다. 라이브 모델 호출은 하지 않습니다.

중단된 Patch Atlas 자동 생성의 도달 불가능한 서버 경로와 중복 OCR 파서/프롬프트를 정리했습니다. 과거 Python 실험 파일과 모델 파일은 보존했습니다.

## 대기 작업 중단

`대기 작업 전부 중단`은 모든 배치의 아직 시작하지 않은 항목만 중단합니다. 분석이 시작된 항목은 생성 대기 중이어도 완료까지 처리합니다. 좌우 분할 이미지는 한쪽이 시작됐으면 양쪽을 함께 완료합니다. 중단된 항목은 오류와 구분해 표시하며 다시 실행하려면 재업로드하세요. 버튼을 누른 뒤 새로 등록한 배치는 정상 실행됩니다.
