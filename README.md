# Comic Translator OAuth App

`ima2-gen`의 OAuth 기반 이미지 생성 흐름을 참고해 만든 만화 이미지 자동 번역 앱입니다.

## 실행

```bash
npm install
npm start
```

## 처리 순서

1. 업로드 이미지 리사이즈 및 2K 이상 해상도 계산
2. `GPT-5.6 Sol / 높음`이 전체 페이지 한 장에서 읽기 순서·모든 텍스트 발생·원문 OCR·한국어 번역을 함께 수행
3. 별도의 `GPT-5.6 Sol / 높음` 호출이 원본 전체를 독립적으로 다시 스캔한 뒤 1차 결과와 대조하여 누락 항목 추가, 잘못 합친 항목 분리, 오인식·읽기 순서·번역을 교정
4. 각 항목에 `T01` 형식의 ID와 원문 바운딩 박스·중심점·페이지 구역을 부여
5. `읽기 순서 + 원문 + 번역문 + 역할 + 대략적 3×3 화면 구역` 체크리스트를 조건으로 `GPT-5.6 Terra / 중간`이 이미지 생성 편집을 요청. 숫자 좌표는 내부 기록에만 유지하며 모델에는 전달하지 않음
6. 결과를 다운로드 폴더에 원본 파일명으로 저장

전체 자동 처리는 최대 3단계입니다. 모든 만화/일본만화 페이지에 `Sol 1차 전체 OCR·번역 → Sol 2차 전체 재검증·수정 → Terra 이미지 생성`을 동일하게 적용합니다. 2차 Sol은 1차 ID나 항목 수를 유지하도록 강제되지 않으며, 원본에서 직접 발견한 누락 텍스트를 추가하거나 잘못 병합된 항목을 분리할 수 있습니다. 자동 경로에서는 크롭 아틀라스나 말풍선별 추가 모델 호출을 사용하지 않습니다.

여러 페이지는 분석 워커 2개와 이미지 생성 워커 2개로 파이프라인 처리합니다. 서로 다른 페이지의 분석과 생성은 겹쳐 실행되지만, 한 페이지 내부의 `Sol 1차 → Sol 2차 → 이미지 생성` 의존 순서는 유지합니다. 전체 모델 호출은 동시에 최대 4개로 제한하며, 고정 OCR 대기는 사용하지 않습니다. 429나 일시 오류가 발생할 때만 지수 백오프와 무작위 지연으로 재시도합니다.

만화/일본만화 프롬프트 계약 버전은 서버 시작 로그의 `Comic OCR/render contract`에서 확인할 수 있습니다. 현재 버전은 `coarse-anchor-v6-sol-double-check-latin-tail-presence-lock`입니다. 일본만화 모드에서는 원본의 영문/라틴 문자를 번역하거나 한글로 음역하지 않습니다. 순수 영문 문구는 원본 픽셀을 그대로 유지해 생성 대상에서 제외하고, 영문과 일본어가 섞인 문구는 영문 부분을 그대로 둔 채 일본어 부분만 한국어로 교체합니다. 말풍선·사고풍선·캡션은 꼬리 개수 0을 포함한 원본의 꼬리 유무와 형상을 완성된 상태로 취급하며, 대사나 인물 위치를 근거로 새 꼬리·포인터·연결선을 추론하거나 생성하지 않도록 이미지 생성 프롬프트 전 경로에서 잠급니다.

## 결과 수정과 실패 복구

- 실패 항목은 붉은 카드로 표시되며 실패 원인을 카드 안에서 바로 확인할 수 있습니다.
- 실패 카드의 `텍스트 영역 편집` 또는 `보호영역 편집`으로 저장된 전처리 원본 위에서 영역을 다시 칠한 뒤 `이미지 생성 재실행`을 누를 수 있습니다. OCR·번역 데이터가 이미 있으면 영역 수정 여부와 무관하게 해당 데이터를 재사용하여 이미지 생성부터 실행합니다. 분석데이터가 아예 없는 실패 항목만 Sol 이중검증부터 실행합니다.
- 완료 카드의 `번역수정`에서 인식 원문, 번역문, 역할, 글자색 힌트, 대략적 위치와 읽기 순서를 수정할 수 있습니다. `수정사항만 저장`은 현재 이미지를 유지하고, `저장 후 이미지 재생성`은 수정 데이터를 곧바로 새 이미지에 반영합니다.
- 완료 카드의 `생성본 복구 편집`은 기존처럼 원본/자동복구 전 생성본을 브러시로 합성하는 최종 수동 보정 기능입니다. 편집기 안의 `생성본 추가요청`을 누르면 글자색·강조·크기·배치처럼 이번 생성본에서 지킬 짧은 지시를 최대 1000자까지 적어 새 생성본을 만들 수 있습니다. 새 결과가 준비되면 브러시 편집은 초기화되고, 곧바로 새 결과를 기준으로 복구 편집을 이어갑니다.
- 상단의 `번역 기록 지우기`는 화면의 배치 기록과 저장된 OCR·번역 분석데이터만 한꺼번에 지웁니다. 다운로드 폴더의 결과 이미지와 임시 이미지 파일은 유지하며, `찌꺼기 삭제`와 별개로 동작합니다.
