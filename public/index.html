판갤 만화번역기

모든 만화 페이지를 Sol이 1차로 전체 판독·번역하고, 별도의 Sol 호출이 원본 전체를 독립적으로 다시 훑어 누락·병합·순서·번역 오류를 교정한 뒤 한국어 번역본을 생성합니다.

업데이트 로그 · 2026-08-03

  • 양면 페이지가 원본 2K 범위를 초과할 때 자동으로 4K급 해상도로 생성합니다.
  • 번역 목록의 개별 이미지에 좌우 분할 버튼을 추가했습니다.
  • 분할한 좌·우 페이지를 각각 독립적으로 분석·번역·생성한 뒤 원래 순서로 자동 합성합니다.
  • 직접 칠한 텍스트 영역과 보호영역 좌표도 각 분할 페이지에 맞게 자동 변환합니다.
자동 모델 처리 1. Sol 높음 · 전체 페이지 읽기 순서 + OCR + 한국어 번역 2. Sol 높음 · 원본 전체 독립 재스캔 + 누락/병합/순서/번역 교정 3. Terra 중간 · 이미지 편집 요청 병렬 처리 · 페이지 분석 2개 + 이미지 생성 2개 · 전체 호출 최대 4개 모든 만화 페이지가 동일하게 Sol 이중검증을 거칩니다. 2차 Sol은 1차 목록에 묶이지 않아 누락된 글자를 새 항목으로 복구할 수 있습니다. 전체 처리는 최대 3단계이며 크롭 아틀라스나 말풍선별 추가 호출은 사용하지 않습니다.

한 줄에 `원문=번역문` 형식으로 입력하세요. 저장은 브라우저에 유지됩니다.

이미지 여러 장을 드래그해서 올리거나 클릭해서 선택

선택한 파일들을 순차적으로 번역하고 결과는 다운로드 폴더에 같은 이름으로 저장됩니다.
