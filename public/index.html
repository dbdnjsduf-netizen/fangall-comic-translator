만화 이미지 자동 번역기

Sol 낮음으로 한 번 분석하고, 불확실한 경우에만 Sol 높음으로 추가 검증합니다. 한국어 글자는 원본의 서체 느낌을 살리면서 선명하게 출력합니다.

자동 모델 처리 Sol 낮음 · OCR·번역 1회 → 불확실할 때만 Sol 높음 1회 → 이미지 생성 만화·일본만화·문서에 적용됩니다. 카드게임은 이미지 직접 번역을 유지합니다. 분석이 끝나도 불확실한 항목은 결과에 표시합니다.

추가 검증은 모델의 불확실성 또는 코드 검사 문제를 기준으로 한 번만 실행합니다. 이전 Terra 선택은 Sol 권장 방식으로 전환됩니다. 저장된 번역이 있는 재생성은 분석을 반복하지 않습니다. 기존 Sol 높음 방식의 문서는 1회만 분석합니다.

새 옵션을 사용하려면 서버 재시작이 필요합니다. 진행 중인 번역이 끝난 뒤 번역기를 다시 실행하고 이 화면을 새로고침해 주세요.

GPT 이미지 모델

사용자사전과 별도로 이미지 생성에 전달합니다. 최대 4,000자. 모델과 요청은 브라우저에 저장되며, 새 실행과 재생성에 현재 설정을 적용합니다. 저장된 OCR·번역문은 다시 분석하지 않습니다.

한 줄에 `원문=번역문` 형식으로 입력하세요. 저장은 브라우저에 유지됩니다. 문서/PDF 번역과 카드게임 번역에는 아컴호러 고정 용어 60개가 자동 적용되며 사용자사전보다 우선합니다.

이미지 여러 장을 드래그해서 올리거나 클릭해서 선택

선택한 파일들을 순차적으로 번역하고 결과는 다운로드 폴더에 같은 이름으로 저장됩니다.
